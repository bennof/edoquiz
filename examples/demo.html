A multiple-choice quiz widget that quizzes you on itself. Answer the questions, then read on to see how it is built.

The result event

When the last question is answered, the container fires an edoquiz-completed event with every answer. The widget itself sends nothing anywhere — what to do with the results is up to the page. Finish the quiz above to see the event's detail here:

(waiting for a finished quiz)

Questions from a file, with a backup

This quiz loads its questions from questions.json via data-url. If that fails — offline, HTTP error, invalid JSON — it falls back to the small data-content pool. It also sets data-redo="false": no “Try again” button.

The markup

A quiz is any element with data-type="quiz"; give it the class quiz-widget for the styling. Questions are a JSON array — correct is the index of the right option:

<div id="my-quiz" class="quiz-widget" data-type="quiz"
     data-title="Capitals" data-count="2"
     data-content='[
       {"question":"Capital of France?","options":["Paris","Rome","Oslo"],"correct":0},
       {"question":"Capital of Norway?","options":["Oslo","Bern","Riga"],"correct":0}
     ]'></div>

More to know

Every quiz starts on a start screen, shuffles questions and answers, marks each answer right or wrong straight away, and ends with a percentage. Several quizzes on one page work independently. The button in the corner of each quiz switches it to fullscreen. data-count limits how many questions are drawn from the pool; without it, all are used.
